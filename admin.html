    How it will look

    Add to the banner

    Upcoming, current and past exhibitions. The website sorts them by date by itself, so on the day a show opens it moves to “On now”, and when it ends it moves to “Past exhibitions”. The paintings you pick for a show stay private unless you choose to show them. Nothing changes on the website until you press Publish changes.

    Change any wording on the website: headings, menu, descriptions, group names, buttons and your contact details. Type over the text, then press Publish changes. “Reset” puts the original wording back. Words in curly brackets, like {shipsTo}, are filled in automatically, so leave them as they are.

    Print sizes and prices

    Every painting that offers prints uses this list. Changing a price here only changes what the website shows: a Stripe link keeps the price it was made with, so after changing a price, make new links with the print script and import them below.

    Print payment links

    Turn prints on for every painting, then import the CSV a Stripe script made (columns id, size, payment_link). Each painting gets one link per print size, and a row with the size "original" sets the original's price and payment link. Nothing goes live until you press Publish changes.
